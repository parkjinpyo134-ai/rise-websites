## 실행

저장소에는 영상과 이미지가 포함되어 약 570MB입니다. GitHub 저장소의 HTML 파일 화면은 홈페이지 실행 화면이 아닙니다. 온라인 주소로 서비스하려면 별도 정적 웹 호스팅 설정이 필요합니다.
