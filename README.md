# RISE 웹사이트

- [절단 시뮬레이터](https://parkjinpyo134-ai.github.io/rise-websites/simulator/)
- [결과물 한눈에 보기](https://parkjinpyo134-ai.github.io/rise-websites/results/)

홈페이지 실행에 필요한 코드와 사진·배치도·GIF·영상만 보관합니다.

- `simulator/`: 시뮬레이터 화면, 동작 계산, 스타일
- `results/`: 결과물 뷰어, 미디어, 폰트 및 라이선스
- `index.html`: 두 홈페이지로 연결되는 시작 화면
- `.nojekyll`: GitHub Pages 정적 파일 배포 설정

사진·배치도·GIF는 기존 파일이며, 영상은 웹 재생용 720p H.264 변환본입니다.

시뮬레이터의 **결과물 설계**에서 1·2·3번 설계를 선택해 바로 불러오거나 JSON을 내려받을 수 있습니다. 파일은 설계 형상을 재생하며, 실험 중 별도로 보정한 최종 모터 펄스는 포함하지 않습니다.
