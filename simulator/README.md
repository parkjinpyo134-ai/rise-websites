# RISE 절단 시뮬레이터

승인된 UI와 2026-11-02 실측 보정 기준을 반영한 로컬 앱입니다.

## 실행

`node prototype/serve.cjs` → http://127.0.0.1:4173/

바탕화면의 `RISE 시뮬레이터 (복사본)` 바로가기로도 실행할 수 있습니다. `index.html`을 직접 열면 계산과 재생은 오프라인으로 동작하고, Pretendard·Tossface 웹폰트는 인터넷 연결 시 로드됩니다.

## 설계 불러오기와 재생

1. `RISE_실행_v7.ipynb`의 8단계에서 절단선을, 8.5단계에서 모터 계획을 생성합니다.
2. `설계 불러오기`에서 `*_simulation.json`을 선택합니다. 브라우저에서 파일 첨부가 어렵다면 `작업 설정 → JSON 텍스트 붙여넣기`에 JSON 전체 내용을 붙여넣습니다.
위쪽에서 출발해 아래로 그린 후 위쪽으로 복귀하는 과정을 1왕복으로 표시합니다. 슬랩 기울기와 X·회전 펄스는 유지됩니다.

3. `전체 생산 재생`은 슬랩·X Initialize부터 마지막 X 원점 복귀까지 연속 재생합니다. 같은 버튼으로 정지·재개합니다.
4. 오른쪽에서 왕복을 선택한 후 `선택 왕복 재생`으로 해당 구간을 확인합니다. 처음 실행하면 먼저 Initialize합니다. 개별 구간 탐색은 앞선 구간을 완료한 상태의 미리보기이며 전체 생산 검증은 전체 재생으로 확인합니다.
5. `처음부터`는 원점 미확정 시작 상태로 초기화합니다. 탭을 숨기면 자동 일시 정지합니다.

Python JSON의 목표 펄스와 모터별 원점을 그대로 사용합니다. 숫자를 변경하려면 Python에서 다시 내보내세요. CSV·직접 입력은 브라우저에서 새 보정 기준으로 미리보기 계획을 계산합니다. 원점 밖 절단선이 있으면 재생을 차단합니다.

## 최신 실측 기준

- X축: `(96,500 − 36,424) / 150 = 400.506666667` 펄스/mm.
- 명목 리드 4mm, 8분주·1,600펄스/모터 회전. 실제 거리 환산은 실측 펄스/mm를 사용합니다. Y축 리드는10mm이며 Y 펄스 계산은 하지 않습니다.
- 모터 순서 Orange·Red·Yellow·Pink의 원점 X(mm): `90.9448032492, 94.9397429922, 135.3885078900, 135.3885078900`.
- 슬랩 우측 끝에서 각 원점까지: `59.0551967508, 55.0602570078, 14.6114921100, 14.6114921100`mm. 이 영역도 제품 배치에 사용하며, 절단선의 도달 가능 여부만 제한합니다.
- X 작업 방향은 내부 좌표 X−, motor4 입력은 양수 HIGH 펄스로 표시합니다. 원점 탐색 펄스 수는 가정하지 않으며 리미트 감지 후0을 확정합니다.
- X 1–399펄스는400, 회전1–9펄스는10. 0은 그대로 유지합니다.
- 슬랩 90°=610펄스. **작업각0°만 실제180°=1,220펄스**입니다. 실제 Initialize는0°·0펄스입니다.
- 매 왕복 후 X Initialize. 각도 변경 전 슬랩 Initialize. 같은 각도의 연속 왕복은 슬랩 각도를 유지합니다. 미사용 펜은 X 원점 고정·공유Y 동행입니다.
- 형상·절단선·배정이 일치하는 실험 기준은 Python이 보관한 명령을 사용합니다. 현재5번은 `design005_center_priority_v2.json`, 공통 기준은 `center_priority_v2.json`입니다. 41번에 과거 실험 펄스를 강제로 적용하지 않습니다.
- 과거 JSON은 파일에 기록된 원점·펄스를 보존하여 재생하고 이전 기준임을 표시합니다.

## UI 모듈

- `model.js`: 좌표·모터·계획 검증·시간별 실제 상태. UI와 독립적입니다.
- `simulator.js`: 파일 입력, 설정, 화면과 재생 모듈 연결.
- `ui/top-down-motion.js`: 위쪽 출발 → 아래쪽 그리기 → 위쪽 복귀. Y 위치·펜 접촉·누적 선·완료 수를 일관되게 계산하며 원본 X·회전 명령을 변경하지 않습니다.
- `ui/playback.js`: 실제 시간표의 전체·개별 재생, 정지·재개.
- `ui/machine-view.js`: 실제 plan/state를 SVG에 투영. 화면 Y 방향만 표시 기준으로 바꾸며 펄스와 실제 좌표를 수정하지 않습니다.
- `ui/machine-skin.js`: 프레임·레일·펜·컨트롤러.
- `ui/slab-surface.js`: 슬랩 재질과 제품 면.
- `ui/motor-monitor.js`, `plan-panel.js`, `file-actions.js`: 모터 표시, 작업 목록, JSON·CSV 입출력.
- `ui/tokens.css`, `layout.css`, `controls.css`: Open Color 색상·배치·컨트롤. 아이콘만 Tossface 원래 색상을 유지합니다.

슬랩300×60mm 대비 표시 프레임 폭500mm, 작은 회전판, 하단 컨트롤러, 연한 파란 슬랩과 파란 절단선으로 구성합니다. 예정선은 입력 좌표이고 실제 그린 선은 정수 펄스 및 실측 보정이 반영된 경로입니다. 두 선이 다르면 구분해 표시합니다. 기구 간 충돌·펜 폭·실제 위치 반복 정밀도는 검증하지 않으며 실제 장비 제어도 하지 않습니다.
