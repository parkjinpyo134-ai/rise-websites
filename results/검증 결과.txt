• 설계 선택, 탭 이동, 사진 선택, 확대/닫기, 키보드 조작 확인
• 320 / 390 / 768 / 1024 / 1440px 화면 너비에서 가로 넘침 없음
• Pretendard / Tossface 로컬 폰트 로딩 확인
• 외부 네트워크 요청, 누락 리소스, JavaScript 실행 오류 없음
