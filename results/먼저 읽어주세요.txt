RISE ICT · 결과물 라이브러리
===========================

실행 방법
1. 받은 ZIP 파일을 원하는 폴더에 '모두 압축 풀기' 합니다.
2. 풀린 rise-results-viewer 폴더의 index.html을 더블클릭합니다.
3. Chrome 또는 Microsoft Edge에서 열어 주세요.
   다른 프로그램으로 열리면 index.html을 우클릭 → 연결 프로그램 → Chrome / Edge.

설치, 로그인, 인터넷 연결이 필요하지 않습니다.
실행 프로그램이나 별도의 서버를 설치하지 않아도 됩니다.

사용 방법
• 상단에서 1·2·3번 설계를 선택합니다.
• 배치도 · 수치 / 시뮬레이션 / 구동 영상 / 결과 사진 탭을 선택합니다.
• 영상은 재생 버튼을 눌러 시작합니다. 음량, 구간 이동, 전체화면은 기본 플레이어를 사용합니다.
• GIF는 시뮬레이션 탭에서 자동 반복 재생됩니다.
• 사진과 배치도는 '크게 보기'를 누르면 확대됩니다. 사진은 좌우 화살표 키로 넘길 수 있습니다.
• 확대 화면은 닫기 버튼 또는 Esc 키로 닫습니다.

다른 사람에게 전달할 때
• ZIP 전체를 보내 주세요. index.html만 보내면 이미지·영상·폰트가 누락됩니다.
• 폴더 전체를 USB로 복사하거나 ZIP을 공유 드라이브에 올려 전달할 수도 있습니다.
• 압축파일 안에서 바로 실행하지 말고 먼저 모두 압축을 풀어 주세요.
• media, assets, licenses 폴더와 app.js, media-data.js, styles.css는 함께 보관합니다.
• 폴더 전체는 다른 위치로 옮기거나 상위 폴더 이름을 바꿔도 됩니다.
• 영상은 파일 크기가 있으므로 메일 첨부 제한을 넘으면 파일 전송 또는 드라이브 링크를 이용하세요.

포함된 자료
• 설계 3종 / 배치도 3장 / 원본 GIF 3개 / 결과 사진 6장 / 구동 영상 16개
• 배포용 영상: 브라우저 호환성을 위해 HEVC 원본을 H.264 / AAC, 720p MP4로 변환했습니다.
• 영상은 전체 길이로 수록했으며, 원본 1080p보다 해상도·화질이 낮습니다.
• GIF, 결과 사진, 배치도는 원본 파일을 사용합니다.
• Pretendard와 Tossface 폰트는 오프라인으로 포함되어 있습니다. 라이선스는 licenses 폴더에 있습니다.

실행이 안 될 때
• ZIP을 모두 풀었는지, media 폴더가 index.html 옆에 있는지 확인하세요.
• 공유 드라이브의 미리보기 대신 ZIP을 다운로드한 뒤 로컬에서 실행하세요.
• Chrome 또는 Edge에서 직접 열어 보세요. 회사·기관의 보안 정책에 따라 로컬 HTML 실행이 제한될 수 있습니다.
• 휴대폰 파일 앱과 메신저 내부 미리보기는 실행 환경이 다르므로 PC 브라우저를 사용하세요.

이 배포본은 오프라인 파일 공유용이며, 공개 웹 주소로 게시된 사이트는 아닙니다.
검증 범위와 결과는 배포 파일과 함께 제공되는 검증 결과를 참고하세요.
